# KYRA Bottles — Free Website

Files:
- index.html
- style.css
- script.js
- website-preview.png (visual reference)

Before publishing:
1. Open script.js.
2. Replace WHATSAPP_NUMBER with the KYRA Bottles WhatsApp number.
3. Upload all files to a GitHub repository.
4. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → /root.

The site is responsive and works on mobile.
